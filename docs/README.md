# Documentation Map

Start here when resuming the project:

1. `MASTER-PLAN.md` — long-lived architecture, safety rules, authority model, and roadmap.
2. `CURRENT-STATUS.md` — exact current physical baseline/candidate and acceptance state.
3. `ARCHITECTURE.md` — canonical live source/tooling structure.
4. `TESTING.md` — build/test/device acceptance workflow.
5. `REPORTS.md` — shareable diagnostics locations and secret-exclusion rules.
6. `RELEASE-CHECKLIST.md` — pre-release and physical acceptance checklist.
7. `history/INDEX.md` — chronological step records.

A generated handoff can still be useful as a snapshot, but the documents above are designed to be sufficient to resume work without one.
